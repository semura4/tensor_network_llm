**対象**: exchange-only (EO) シリコンスピン量子ビット向けパルス制御ミドルレイヤ `eo_pulse_ir`
**ブランチ**: `claude/eo-pulse-control-ir-hub60a`
**作成日**: 2026-06-23
**ステータス**: 中核機能・中核結果ともに完成。技術提供資産（非公開）として整備済み。

---

## 0. 要約（1段落）

論理回路を「EOネイティブゲート → 交換パルス列 → cryo-CMOS コントローラ・メモリ予算」へ落とす、依存の軽いミドルレイヤを実装した。numpy だけの物理シミュレータを併設し、ゲートを実機報告値に較正し、EO 実機で支配的な2つの誤差軸（電荷ノイズ＋バレー位相広がり）の下でゲートを設計・評価できる。**核心の成果は、反証可能な device-anchored 結果が1つ立ったこと**：同時ノイズ下でロバスト CNOT が平均忠実度 **0.950** を保ち、標準ゲート（0.826）だけでなく「より短く電荷ノイズに有利な厳密ゲート」とその**電荷ノイズゼロ理想上限（0.932）**すら上回る。優位性はバレー軸にあり、パルス短縮では買えない。

> **本プロジェクトが目指していないもの**（スコープの明示）:
> 新規な2量子ビットゲート合成の物理 / 表面符号デコーダ / fab・cryo-CMOS の再実装。
> 本成果は **統合** と **1つの反証可能な結果** に価値がある（新規物理の主張ではない）。

## 3. 核心の結果（反証可能な主張）

較正電荷ノイズ **σ = 0.91% dJ/J** かつ バレー位相広がり **±0.3π** の同時アンサンブル下:

| ゲート | パルス数 | 平均F（同時） | F at Δφ=0（電荷のみ） |
|---|---:|---:|---:|
| 標準 CNOT | 34 | 0.826 | 0.993 |
| コンパクト厳密 CNOT | 27 | 0.926 | 0.991 |
| コンパクト・**電荷ノイズゼロ（上限）** | 27 | **0.932** | 1.000 |
| **同時ロバスト CNOT** | 34 | **0.950** | 0.974 |

**論理の積み上げ**:
- 短い 27 パルスゲートは電荷軸で有利で、同時ノイズ下でも 0.826→0.926 と実際に改善する（「少パルスにすれば勝てる」直感は途中まで正しい）。
- そのゲートから電荷ノイズを完全に消した理想曲線でも **0.932 で頭打ち**。これはパルス数を減らすほど電荷誤差が減るという事実から、DiVincenzo 19 パルス・Fong–Wandzura 22 パルスを含む**あらゆる短い厳密ゲートの上限**になる。
- ロバストゲート（0.950）はその上限すら上回る。**優位性はバレー軸にあり、パルス短縮では買えない**。

再現: `python scripts/eo_robust_compare.py`（CI は `--quick`）。

## 4. デバイス整合（較正とバレー）

**較正**: 単一の準静的な辺ごとの乗算的面積ノイズ `a_eff = a·(1+ε), ε~N(0,σ)` を、検証済み CNOT が報告2量子ビット忠実度 0.990 に乗るよう σ をフィット。**σ = 0.90% dJ/J** が以降のゲート集合をパルス数だけから予測する:

| ゲート | パルス | 予測 F |
|---|---:|---:|
| H (1Q) | 3 | 0.99950 |
| X (1Q) | 3 | 0.99984 |
| CNOT (2Q) | 34 | 0.99000 |
| SWAP (2Q) | 27 | 0.99199 |
| CXSWAP (2Q) | 48 | 0.98859 |

ノブ1つで実機の 1Q/2Q 階層（≈99.9% / 99%）を再現。σ≈1% はシリコンの電荷ノイズとして妥当。

**バレーボトルネック**（`valley_splitting_research.md` 一次資料17本に基づく3点）:
1. E_VS は無秩序な確率変数（10–300 µeV, チップ内分布）。ボトルネックは**ピーク値でなく一様性／歩留まり**。
2. ドット間のバレー位相差が交換を抑制（`J_eff ≈ J·cos²(Δφ/2)`, Δφ=π で零）。**両ドットで E_VS が大きくても**起きる（Tariq–Hu, npj QI 8, 53, 2022）。
3. 小／非一様な E_VS が論理部分空間からのリーケージ路を開く（Buterakos–Das Sarma, PRX Quantum 2, 040358, 2021）。

シミュレータはこれを明示的に持つ（4準位 spin⊗valley）：位相整合時は spin-only 検証済み CNOT を厳密再現、E_VS≫J でバレーリーケージを零に抑制、位相不整合は大 E_VS でも交換を detune する。

## 5. 敵対的レビューとその対応

**Reviewer 2 視点の結論**: 各構成要素はいずれも先行研究にプリエンプトされており（Kempe–Bacon–Whaley 可制御性 / KAK / GRAPE・随伴 / Tariq–Hu バレー抑制 / アンサンブルロバスト制御 / MPS）、**科学的新規性は限定的**。一方で、正しく・再現可能で・よく統合されている。→ 新規物理の論文ではなく、**統合 + 1つの device-anchored 結果**として位置づけるのが妥当。

**最強の反論への対応**:「なぜ最短既知の厳密ゲート（DiVincenzo 19 / Fong–Wandzura 22）と比べない？」
→ 環境がarXiv等の全文取得を全て 403 で遮断するため FW の literal な22面積値は取得不能。そこで**電荷ノイズゼロ上限**という、特定数列に依存しない厳密な上界で FW 級を一括して封じた（§3）。この上界論法により literal な FW 列なしでも主張は崩れない。

## 7. スコープと限界（正直版）

- **新規物理なし**。貢献は統合 + 1つの device-anchored 結果。
- **較正は現象論的**（1つの数に1ノブをフィット、第一原理ノイズモデルではない）。
- **バレーモデルの範囲**: `cos²(Δφ/2)` 抑制と4準位リーケージ空間まで。熱励起バレー占有（≳5k_BT 則）、E_VS=E_Zeeman の spin-valley ホットスポット、空間相関 E_VS ディスオーダーは未実装（自然な次拡張）。
- **ロバスト性の範囲**: 準静的（フィルタ関数）ノイズ、CNOT で実証。同エンジンは全ゲート集合・MPS 上の多qubitブロックへ拡張可能。
